# Security Policy

## Supported Versions

Currently, only the latest release of `cs-edl-bouncer` is supported with security updates. We encourage all users to stay up-to-date with the latest version.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of `cs-edl-bouncer` seriously. If you discover a security vulnerability, please report it immediately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via [GitHub Security Advisories](https://github.com/hononeko/cs-edl-bouncer/security/advisories/new) or by reaching out to the repository owner directly.

Please include the following information in your report:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any suggested mitigations or fixes.

We will acknowledge receipt of your vulnerability report and strive to address it as quickly as possible.
